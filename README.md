# BookStore
A fully functional and responsive online bookstore web application built using HTML, Bootstrap 5, CSS and JavaScript.
## Features

- **Multi-page Architecture:** Includes Home, Books Catalog, About Us, Contact Us, and Shopping Cart pages.
- **Dynamic Book Catalog:** Books are rendered dynamically using JavaScript arrays and objects.
- **Category Filtering:** Filter books instantly by categories (Fiction, Self Help, Technology, Business, Science, etc.).
- **Real-time Search:** Search for books seamlessly by name.
- **Interactive Shopping Cart:** 
  - Add items to the cart.
  - Increase or decrease item quantities with real-time total updates.
  - Persistent cart storage using browser `localStorage`.
  - Delete items and calculate Grand Totals dynamically.
- **Contact & Order Forms:** Interactive forms with validation and confirmation alerts.
